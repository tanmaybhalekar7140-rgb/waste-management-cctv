# Waste Management System Using CCTV (BinSight)

A responsive single-page website for a CCTV-based waste monitoring system.

**Live URL:** https://waste-management-cctv.vercel.app
**Repository:** https://github.com/tanmaybhalekar7140-rgb/waste-management-cctv

## Tools used
HTML, CSS, JavaScript, Git, GitHub, Vercel

## Deployment steps
1. Created a public GitHub repository and uploaded `index.html`.
2. Signed in to Vercel with GitHub.
3. Chose Add New, then Project, and imported the repository.
4. Set the framework preset to Other, with no build command.
5. Clicked Deploy. Vercel published the site.
6. Disabled Vercel Authentication under Settings, then Deployment Protection, so the site is public.
7. Added `vercel.json` for cloud configuration.

## Continuous deployment
The repository is linked to Vercel. Every push to the `main` branch starts a new deployment automatically.

## HTTPS
Vercel issues the SSL/TLS certificate automatically. The site opens over HTTPS with a padlock and no warning, and HTTP requests redirect to HTTPS.
